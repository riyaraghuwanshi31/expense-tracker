# Expense Tracker

A full-stack Expense Tracker application built using **React.js, Spring Boot, Java, Hibernate, and MySQL**.

The application allows users to add, view, update, and delete expenses, manage categories, and track their expenses through a simple dashboard.

## Tech Stack

**Frontend**

* React.js
* JavaScript
* HTML
* CSS
* Vite

**Backend**

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* Maven
* REST APIs

**Database**

* MySQL

## Features

* Add new expenses
* View expense list
* Update expenses
* Delete expenses
* Manage expense categories
* Dashboard for expense tracking
* CRUD operations
* REST API integration
* MySQL database integration

## Project Structure

```text
Expense-Tracker/

```

## Getting Started

### Backend

Navigate to the backend folder:

```bash
cd backend
```

Configure your MySQL database in `application.properties`, then run:

```bash
mvn spring-boot:run
```

### Frontend

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

## Application Flow

